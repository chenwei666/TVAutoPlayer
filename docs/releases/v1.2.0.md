# TVAutoPlayer V1.2.0

V1.2.0 解决部分 Android TV 没有系统文件选择器、导致无法首次选择视频的问题。

## 主要变化

- 内置电视视频选择器，遥控器可直接操作。
- 自动扫描电视内部存储和系统已识别的 U 盘视频。
- 支持一次勾选多个视频，并按勾选顺序循环播放。
- 重新扫描后保留仍可见的勾选项和顺序。
- 系统文件选择器改为可选兼容入口；不存在时不会显示，也不会影响使用。
- 使用 Android 分版本视频只读权限，不申请整盘管理权限，不联网、不上传文件。

## 安装

下载 `TVAutoPlayer-v1.2.0-debug.apk`，在电视允许安装未知来源应用后侧载；或通过 ADB 执行：

```powershell
adb install -r .\TVAutoPlayer-v1.2.0-debug.apk
```

首次打开时允许读取视频，然后在内置媒体库中用遥控器确认键按播放顺序勾选视频并保存。

如果 U 盘视频没有出现，请将文件放到 `Movies/TVAutoPlay`，重新插入 U 盘，等待系统媒体索引完成后选择“重新扫描”。

## 校验与限制

- 本地质量门禁：单元测试、Android Lint、Debug APK 构建全部通过。
- APK 清单：`com.chenwei.tvautoplay`，`versionCode=5`，`versionName=1.2.0`，`minSdk=23`，`targetSdk=36`。
- APK 已通过 ZIP 对齐以及 v1/v2 调试签名验证。
- 本版本为 Debug 签名，正式批量部署请使用企业固定 Release 证书。
- 未连接真实 Android TV；U 盘索引、遥控器、硬件解码和开机自启动仍需在目标电视验收。
