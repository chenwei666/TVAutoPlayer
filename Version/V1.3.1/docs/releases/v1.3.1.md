## 安装

下载 `TVAutoPlayer-v1.3.1-debug.apk`，允许电视安装未知来源应用后侧载；或通过 ADB 执行：

```powershell
adb install -r .\TVAutoPlayer-v1.3.1-debug.apk
```

相同签名覆盖安装会保留播放列表、图片停留时间、声音、画面比例和开机自动播放设置。
