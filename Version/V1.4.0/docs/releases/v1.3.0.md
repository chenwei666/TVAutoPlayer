# TVAutoPlayer V1.3.0

V1.3.0 增加图片轮播和可设置的自动切换时间，并保留原有视频循环播放能力。

## 主要变化

- 图片与视频可以混合加入同一播放列表，并按遥控器勾选顺序无限循环。
- 每张图片可以显示 5、10、15、30 或 60 秒，默认 10 秒；视频播放到结束后自动切换。
- 内置媒体库同时扫描电视存储与 U 盘中的支持图片和视频，并显示 `[图片]`、`[视频]` 标签。
- 支持 JPEG/JPG、PNG、WebP、BMP、HEIF/HEIC；AVIF 需要 Android 14+；GIF 暂不支持。
- 升级时保留 V1.0.0～V1.2.0 的播放列表和设置，旧播放项自动按视频处理。
- 不申请整盘管理权限，不联网、不上传、不修改原文件。

## 安装

下载 `TVAutoPlayer-v1.3.0-debug.apk`，允许电视安装未知来源应用后侧载；或通过 ADB 执行：

```powershell
adb install -r .\TVAutoPlayer-v1.3.0-debug.apk
```

首次使用图片功能时允许读取照片和视频。在设置页连续按“图片切换”按钮可选择停留时间。

建议把视频放入 `Movies/TVAutoPlay`，图片放入 `Pictures/TVAutoPlay`；如果没有立即出现，重新插入 U 盘并稍后执行“重新扫描”。
