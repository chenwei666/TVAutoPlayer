# TVAutoPlayer V1.4.0

V1.4.0 增加应用中英文界面自适应和 GitHub 中英文项目介绍。播放器业务逻辑、播放列表格式和隐私边界保持兼容。

## 主要变化

- 新增完整英文 Android 字符串资源，覆盖播放页、设置页、媒体库、权限、错误和确认提示。
- 应用根据电视系统语言自动显示中文或英文，无需手动选择。
- README 首页增加中英文简介和语言导航。
- 新增完整英文说明 `README_EN.md`，包含功能、安装、开机启动、格式、构建和隐私说明。
- GitHub About 简介升级为中英文，并准确体现图片/视频轮播与开机播放。
- Android 应用版本升级为 `versionCode=8`、`versionName=1.4.0`。
- 新增 `Version/V1.4.0` 完整项目快照。

## 安装

下载 `TVAutoPlayer-v1.4.0-debug.apk` 后侧载；或通过 ADB 执行：

```powershell
adb install -r .\TVAutoPlayer-v1.4.0-debug.apk
```

相同签名覆盖安装会保留播放列表、图片时长、声音、画面比例和开机自动播放设置。切换电视系统语言后，重新打开应用即可加载对应语言。
