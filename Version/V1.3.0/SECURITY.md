# 安全策略

## 支持版本

当前维护版本为 V1.3.x。安全修复会优先发布到最新版本。

## 报告安全问题

请不要在公开 Issue 中披露可被利用的安全漏洞。请通过 GitHub 仓库所有者主页提供的私密联系方式报告，并包含受影响版本、复现条件、影响范围和建议修复方向。

请勿发送真实账号、密码、Token、签名密钥、个人视频或其他敏感数据。收到报告后，维护者会先确认问题，再协调修复和公开时间。

## 安全边界

本应用不联网、不连接数据库、不收集用户数据。内置媒体库仅使用 Android MediaStore 和对应版本的照片/视频只读权限显示系统已索引的媒体，不申请整盘管理权限，不修改或上传媒体；可选系统文件选择器只使用用户明确授权的本地 URI。应用仅保存媒体 URI、显示名称、类型、播放顺序、图片停留时间和非敏感播放偏好，业务日志不记录 URI 或文件名。
