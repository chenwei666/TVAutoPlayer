# 测试说明

## 已确认的公开测试边界

1. 首次启动没有保存视频时，系统要求选择视频。
2. 已保存视频且授权有效时，系统进入可循环播放状态。
3. 文件授权被撤销时，系统要求重新选择而不是崩溃。
4. 开机启动只在开关开启、视频已选择且授权有效时发生。

测试文件：`app/src/test/java/com/chenwei/tvautoplay/PlaybackPolicyTest.java`

## 人工电视验收清单

- 首次打开立即显示系统文件选择器。
- 取消选择后界面可用，不连续弹窗、不崩溃。
- 选择 U 盘 MP4 后立即播放并至少观察两次循环。
- 按 Home 再打开，确认直接播放且无需重选。
- 完全断电重启，确认厂商自启动设置开启时自动进入播放。
- 拔掉 U 盘或删除文件，确认提示重新选择。
- 更换视频后确认旧视频不再播放。
- 验证返回键、菜单键、方向键、确认键的焦点与操作。
- 验证声音开关和两种画面模式。
- 验证 1080p H.264/AAC；按现场需求增加 4K、HEVC、MKV 等样本。
- 连续循环 8 小时，观察卡顿、音画同步、温度和内存。

## 当前测试限制

本开发机没有连接 Android TV、电视盒子或 TV 模拟器，因此无法执行真实解码器、U 盘文件提供器、遥控器和厂商开机策略测试。自动化测试、编译和 Lint 不替代目标硬件验收。
